Risks (pytest.main repeated in one process; these are from pytest behaviour, not read from this repo):
- sys.modules caches: test modules and project modules are imported once, so module-level code runs once; first round holds the import cost (warm-up covers it); conftest/plugins re-register per Config; assertion-rewrite hooks and capture/logging plugins may add a little per run (pytest's own growth was the "next" site, 14 objects per round, in the Pillow ground truth note) and can look like a leak; pass `-p no:cacheprovider`, `-p no:randomly`, `-q`, `--assert=plain`/`-s` choices.
- pytest.main returns an exit code and does not sys.exit, but tests/plugins may call sys.exit or os._exit; wrap in try/except SystemExit like dla_harness.py:155; stdout/stderr capture and fd capture may fight the harness's logs (use `-s` or `--capture=sys`).
- Tests that fail every run: map to exit 2/3 rules as the Java loop (dead units) so a failing-at-first-line test is refused rather than read flat (DlaJUnitHarness.java:452); drop whole files that never pass after run 1 (:320-359).
- Tests that change global state/xdist-order/random seeds, tmp dirs, env vars, warnings filters: growth may come from the test, not the code; session-scoped fixtures in conftest rebuild per pytest.main (new Config), so their cost and their objects are per unit; module-global state of the project persists across units, which is what the probes read.
- Time per round: pytest startup and collection cost per unit (hundreds of ms) vs JUnit launcher 6 ms; use step 1-2, 8 measured rounds, drop slowest files with the time limit (DLA_TIME_LIMIT_SECS). Pillow notes: two files, 17 s.
- Installed vs scratch package, venv not handled, C extensions built outside the scratch copy (Pillow had to copy .so into src/PIL by hand): the loop must import the scratch tree or coverage/probe sites will not match.
- Coverage needs Python 3.12+ (sitecustomize.py:1268); without it targets read `unknown`.
- Not found: a Python counterpart of tests.json/`--next` plan, of a venv/pyenv choice, and of a start-up agent switch for the test loop in the Python branch.
