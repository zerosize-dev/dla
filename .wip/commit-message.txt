Find four more kinds of leak; move four parked fixtures back

Labels
- L-REGISTER accepts growth-series + alloc-stack, as L-HANDLE and L-COLLECT do. A
  registration the runtime holds out of sight (a Go timer before 1.23) has no retention
  path and no count column, only its growing allocation stack.

Python
- The census lists a gc.freeze() call inside a function, and the agent attributes the
  permanent generation to the calling site as the count group py.gc_frozen. Garbage frozen
  after every batch was invisible: it is in no gc generation and no type count.
- The census lists native codec contexts (zlib, bz2, lzma and zstd compressor and
  decompressor objects) as native handles.

Node
- A probe whose root cannot be measured (a function, an opaque value, an object of a class
  with only private fields) says so and writes no column. It read a constant 1, and a true
  finding was refuted on it.
- FinalizationRegistry cells with a live target are a registration holder, owned by the
  one module variable that holds the target. When only Node's own modules grow, heap-graph
  says that and no longer asks for another snapshot.

Go
- New rule go-slice-view-retained: a slice parameter stored un-copied into receiver or
  package state while a caller passes a view of a larger buffer, which pins the buffer.
  Callers are paired with a method through the receiver's declared type.
- Go joins the chain-head-growth rule: a field reassigned from a call on its own value.
  The census lists such a field with the write as its writer.
- A static hit can carry holder, owner and region, and the candidate takes them.
- Command mode reads the heap while the workload runs. The exit record is written after
  main returned, when state owned by a local is already dead, so such a leak read flat. A
  sampler takes go.heap_live.in_run and go.heap_objects.in_run (the floor of the last third
  of the run, after a collection) and a heap profile in the run. Existing columns and driver
  mode are unchanged; the in-run column is the primary heap column only when the trend
  passed it.

Benchmark
- go-ticker-legacy, python-frozen-gc, node-signal-compose-24 and go-header-index pass and
  move from bench/fixtures-open/ to bench/fixtures/ (64 fixtures), with the pair lines of
  go-ticker-modern and node-signal-compose-22 restored. Four stay parked: their README says
  what each still needs.
