9. Stop hook (crates/dla-cli/src/gate_hooks.rs)
- Registered: Stop in SKILL.md frontmatter (command `"${CLAUDE_PLUGIN_ROOT}/bin/dla" gate stop-hook`, line ~27). SubagentStop with `--subagent` in hooks/hooks.json:86-92 (matcher `^dla:worker$`).
- `stop` (842): allows when there is no run, or the run state is not Active. With `--subagent` it finds the worker from the transcript (`worker_in_command`) and uses `stop_worker` (912). Otherwise `stop_core` (868).
- stop_core: `let missing = gate::missing(&view, GateTarget::Final, None); if missing.is_empty() { allow }`. Otherwise it digests ledger line count + `kind:id` of missing items (`digest_of`, 720). If the digest equals the stored one it increments `stop_blocks`, else resets to 1. At `STOP_LIMIT = 3` (line 39) it sets status Incomplete with `incomplete_reason` "stop hook let the stop through after 3 stop attempts with no ledger change: ids" (gate.rs:32 STOP_BLOCKED_REASON) and allows the stop (stderr note). Otherwise it blocks: `{"decision":"block","reason":...}`, exit 0 (HookOut::block, :109).
- block_reason (801): max 1000 bytes (MAX_REASON, :42), first 3 missing items as "- {id}: {description} Fix: {fix}", and "The full list: dla gate check --final". Budget line from budget_note (758). Above the floor: "{left} of {total} budget minutes remain: measure what is open instead of stopping." (787). Under the floor / spent / nothing smaller fits: tells the core to ask the user once to `dla run extend`, else close with a reason and remedy. A worker or unattended run is told to close.
- It fails open on any error (module doc :9-11). Any ledger change (including closing one finding per attempt) changes the digest and resets the counter, so a stream of resolves never reaches the stamp.
